# Реестр проверенных хэштегов

Реестр проверенных инстаграм-хэштегов по визуальным линиям проекта. Хэштеги добавляются сюда автоматически после каждого созданного капшена. Статус проверяется вручную/через поиск перед добавлением. Раз в 3–4 недели весь реестр стоит перепроверять целиком.

**Легенда статуса:** ✅ проверен, безопасен · ⚠️ требует повторной проверки (>30 дней) · ❌ выведен из использования (забанен/деградировал)

## Общие правила ведения реестра

1. Новые теги добавляются только после проверки (ручной поиск в приложении или через сторонний чекер) на предмет бана/ограничения.
2. Мега-теги с десятками миллионов постов не добавляются в принципе — даже если формально не забанены.
3. Приоритет отдаётся нишевым тегам среднего объёма (примерно от нескольких тысяч до пары сотен тысяч постов).
4. Каждая запись помечается датой проверки — это позволяет находить теги, которым больше месяца, для повторной сверки.
5. При обнаружении, что ранее безопасный тег стал банится — статус меняется на ❌ и добавляется комментарий с причиной/датой.
