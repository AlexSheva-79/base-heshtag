# SKILL: Созерцательный рилз в стиле восточного техно-фэнтези

**Триггер:** использовать этот скилл при создании рилза-антологии локаций в восточном фэнтезийном сеттинге (парящие острова, ханьфу, восточная архитектура, фантастическая фауна) с целью «созерцание и желание оказаться в этом мире».

Основан на реальном проекте «Сады на летающих островах» (@fairyteller_art, сентябрь 2026).

---

## 1. Концепция: антология локаций, не сюжет

Рилз — прогулка по 8 разным местам, а не история с завязкой и развязкой. Зритель досматривает, потому что не знает, что будет следующим.

**Три сигнала алгоритма Instagram 2026:** watch-time, saves, sends (пересылки в директ).

**Формула save-триггера:** «сохрани — чтобы возвращаться сюда».
**Формула send-триггера:** «отправь тому, с кем хотел бы оказаться здесь».

## 2. Структура сценария (8 сцен, ~19–22 сек)

| № | Функция | Камера | Героиня | Хрон. |
|---|---|---|---|---|
| 1 | Хук — мгновенный вопрос «что это?» | Low-angle / Bird's eye / Worm's eye | Нет или только деталь | 2.0 с |
| 2 | Расширение мира | Bird's eye / Dutch / Gimbal | В ¾ / сверху | 2.0 с |
| 3 | Уют — интимный план, якорный элемент | Stationary / Worm's eye | Нет | 2.0 с |
| 4 | Эпический масштаб — вау-кадр | Tilt down / Crane down | Нет | 3.0 с |
| 5 | Деталь — остановка, рассмотреть | Dutch / Macro | Рука / силуэт | 2.0 с |
| 6 | Смена ритма — другая атмосфера | Orbit / Reverse pull-out | Нет | 2.5 с |
| 7 | Кульминация — максимальная эмоция | Steadicam / Handheld | Профиль / ¾ | 2.5 с |
| 8 | Финал — тишина, послевкусие | Crane up / Push-in | Спиной или ¾ | 3.0 с |

**Правило камер:** каждый приём — только один раз в рилзе. Вести учёт.

**Сквозной якорь:** один персонаж/существо появляется в сценах 1, 3 и 8. Зритель замечает при пересмотре — дополнительный save-триггер.

**Акцентный цвет-нить:** один насыщенный цвет проходит через все сцены (в проекте «Сады» — алый/crimson).

---

## 3. Палитра и стиль «Острова»

- **Архитектура:** East Asian imperial + steampunk (латунь, шестерни, патина)
- **Палитра:** нефрит, латунь, выветренная охра, бирюзово-изумрудный туман, акцентный цвет
- **Свет:** мягкий рассеянный дневной, бирюзовый отсвет снизу от тумана
- **Мир живой:** всегда горожане в ханьфу, дирижабли, водопады, фауна
- **Ракурсы статики:** нестандартные (low-angle, worm's eye, bird's eye, dutch angle) — не только «на уровне глаз»

## 4. GPT-промпт для статичной сцены (структура)

```
[Ракурс камеры и угол] A [ракурс] shot of [локация]...

FOREGROUND: [передний план — главный элемент / существо]
BACKGROUND: [задний план — острова, туман, водопады, дирижабли]
FIGURES: [фоновые персонажи с конкретными действиями]

STRICT NEUTRAL COLOR BALANCE: maintain neutral, true-to-life color balance
throughout. Actively counteract warm yellow/amber color cast. Keep cool
undertones in shadow areas.
[Акцентный цвет] must be pure vivid saturated [цвет] — not brick, not
terracotta, not muted.

Vertical portrait orientation, 9:16 aspect ratio.
```

### Обязательный антикаст-блок (вставлять в КАЖДЫЙ промпт):
```
STRICT NEUTRAL COLOR BALANCE: maintain neutral, true-to-life color balance
throughout. Actively counteract warm yellow/amber color cast. Keep skin tones
cool and natural, preserve cool undertones in shadow areas, keep white fabric
truly white rather than cream/ivory-tinted.
```

### Если в кадре алый/красный:
```
The crimson must be pure vivid saturated crimson — bright clean red,
not brick, not terracotta, not coral, not orange-red.
```

## 5. Цветокоррекция (отдельный промпт)

Если после генерации есть каст — делать отдельным промптом, называть каждую зону:

```
Color correction only — do not change composition, figures, or any other element.

Fix only these zones:
1. [Зона 1]: has [тёплый/жёлтый/кирпичный] cast → shift to [целевой цвет]
2. [Зона 2]: has [каст] → shift to [целевой цвет]

Do NOT touch: [перечислить всё что правильно].

Vertical portrait orientation, 9:16 aspect ratio.
```

**Типовые проблемы ChatGPT/DALL-E:**
- Зелень (бамбук, мох, листья лотоса) → жёлто-зелёный → исправлять: «cool deep green, not yellow-green, not olive»
- Алый/красный → кирпич/терракота → исправлять: «pure vivid saturated crimson»
- Небо и туман → тёплый белый/серый → исправлять: «cool teal-emerald mist, deeply saturated»

## 6. Grok-промпт для анимации (структура)

```
[face lock, если лицо в кадре]:
@imageN is the character reference — exact identity lock throughout. Face must
not drift, morph or change at any point.

@image1 [Описание движения камеры — конкретный приём]:
[Камера]: [точное описание движения с параметрами]

HERO — @imageN [имя] [действия]:
- [Конкретное физическое действие 1 — глагол + часть тела]
- [Конкретное физическое действие 2]
- [Конкретное физическое действие 3]

WIND PHYSICS — applied to every soft element simultaneously:
- [Волосы]: lifts and flows continuously in a gentle breeze...
- [Рукава/ткань]: billow and drift outward, rippling in slow waves...
- [Лепестки/лианы]: sway gently, some petals detaching and drifting...

[ФАУНА — если есть]:
[Существо]: [цепочка конкретных физических действий]

BACKGROUND: [жизнь на заднем плане — дирижабли дрейфуют, туман дышит, водопады текут]

Audio: [диегетика — минимум 5 источников]. [Без фразы «NO MUSIC»]

Shot on Arri Alexa 65, [фокусное]mm, f/2.8 ISO 800, [глубина резкости], 
natural motion blur on [движущиеся элементы].
```

### Пять правил анимации:

**1. Все живые существа — в движении**
Каждый персонаж/существо в кадре получает конкретную физику тела:
- ❌ «стоит и смотрит вверх»
- ✅ «медленно поднимает правую руку и указывает вверх, поворачивает голову к соседу, рот приоткрывается»

**2. Физика ветра — для каждого мягкого элемента отдельно**
Волосы / рукава / лепестки / лианы / кисти украшений — каждый прописывается отдельной строкой.

**3. Физика бабочки (для ящериц с крыльями бабочек)**
```
Butterfly flight physics — NOT dragonfly flutter. Each wingbeat is slow,
broad and deliberate: wings sweep fully downward in a long arc, pause briefly
at the bottom, then sweep back up. Body bobs gently up and down.
Flight path drifts and wavers, not a straight line.
```

**4. Face lock (если лицо в кадре)**
Всегда загружать карту персонажа как отдельный @imageN референс. Без face lock лицо «плывёт» при движении камеры.

**5. Звук — только диегетика, без «NO MUSIC»**
Просто не упоминать музыку. Прописывать 5–7 конкретных источников звука среды.

## 7. Протокол работы над каждым промптом

1. Прочитать area-файл активного рилза и релевантные SKILL-файлы
2. Показать **только блок самопроверки** — без промпта
3. Ждать подтверждения
4. Показать промпт
5. Следующий промпт — только после утверждения предыдущего

### Блок самопроверки (формат):
```
Проверка:
- Инструмент: [ChatGPT-DALL-E / Grok Video]
- Референсы: [image1 = ... / image2 = ...]
- Identity/geometry lock: [что зафиксировано или «не применимо»]
- Цветокоррекция: [встроена / отдельный промпт]
- Камера (анимация): [приём], ранее использованные: [список]
- Звук (Grok): только диегетика ✓
```

## 8. Капшион (структура)

1. **Хук** — ≤125 символов (это граница обрезки ленты)
2. **Атмосфера** — 1–2 строки с эмодзи
3. **Save-триггер** — явная фраза
4. **Send-триггер** — явная фраза с «отправь тому, кто...»
5. **Провокация досмотреть** — «досмотри до конца — там...»
6. **Хэштеги** — 3–5 нишевых (sweet spot: 5K–300K постов)
